# Velum

Сайт магазина кровельных и фасадных материалов в Атырау — [velum.kz](https://velum.kz).

Стек: [Astro 7](https://astro.build) (статические страницы + одна серверная функция),
TypeScript, хостинг на Vercel. Заявки с форм уходят в Telegram.

## Разработка

Нужен Node.js 22.23.4 или новее (чётная версия: 22, 24).

```bash
npm install
cp .env.example .env   # впишите токен бота и id чата, чтобы проверить отправку заявок
npm run dev            # http://localhost:4321
```

| Команда            | Что делает                                                                              |
| ------------------ | --------------------------------------------------------------------------------------- |
| `npm run dev`      | Локальный сервер с автообновлением                                                      |
| `npm run build`    | Проверка типов и сборка для Vercel                                                      |
| `npm test`         | Модульные тесты (Vitest)                                                                |
| `npm run test:e2e` | Тесты в браузере (Playwright). Перед первым запуском: `npx playwright install chromium` |
| `npm run format`   | Форматирование кода (Prettier)                                                          |

## Структура

| Путь                     | Что там                                                                      |
| ------------------------ | ---------------------------------------------------------------------------- |
| `src/pages/`             | Страницы: `index`, `taplink`, `thanks`, `404` и `api/send.ts` (приём заявок) |
| `src/components/`        | Шапка, секции главной, модальное окно с формой                               |
| `src/layouts/Base.astro` | Общий `<head>`: SEO-теги, Open Graph, шрифт                                  |
| `src/lib/`               | Данные компании, маска и проверка телефона                                   |
| `src/scripts/main.ts`    | Модальные окна, маска телефона, FAQ, отправка форм                           |
| `src/styles/`            | Стили страниц                                                                |
| `src/assets/`            | Картинки и шрифт — Astro сам сжимает их в AVIF/WebP                          |
| `public/`                | Файлы как есть: `robots.txt`, иконки, картинка для соцсетей                  |
| `tests/`                 | Модульные тесты; `tests/e2e/` — тесты в браузере                             |
| `drafts/`                | Старые черновики, в сборку не входят                                         |

## SEO для новых страниц

Каждая сборка в CI проверяется скриптом `npm run seo` (`scripts/seo-check.mjs`). Он остановит
сборку, если правило нарушено:

- у страницы есть `title` (до 60 символов у индексируемых), `description` (70–160 символов),
  один `<h1>`, `canonical` на `https://velum.kz/...`, Open Graph и `lang="ru"`;
- `title` и `description` не повторяются у разных страниц;
- у всех картинок есть `alt` (у декоративных — пустой);
- JSON-LD разметка без ошибок;
- в `sitemap` — все канонические страницы и только они.

Правила для каталога:

- страница модели — каноническая, с разметкой `ProductGroup` всех вариантов и таблицей покрытий;
- страница варианта (цвет/покрытие/толщина) — для покупателя, её `canonical` ведёт на модель,
  в sitemap её нет; так Google не считает сотни похожих страниц дублями;
- новая страница создаётся через `Base.astro` или `CatalogLayout.astro`: они ставят все SEO-теги.

Как опубликовать сайт и привязать домен — в [DEPLOY.md](DEPLOY.md).
